# Kingdom Raycast / Script Commands

Shell out to orchestrator API and npm scripts — no duplicate logic.

## Setup

1. Run Kingdom with control API: `npm run dev` (Vite :5173 + API :5174).
2. Run sync at least once: `npm run sync`.

## Commands

```bash
# Sync all venture data
bash scripts/raycast/kingdom-raycast.sh sync

# Open venture Run tab in browser
bash scripts/raycast/kingdom-raycast.sh open-venture whatsapp-voice run

# Start/stop venture dashboard on Mac
bash scripts/raycast/kingdom-raycast.sh start-dashboard whatsapp-voice
bash scripts/raycast/kingdom-raycast.sh stop-dashboard whatsapp-voice

# Open repo in Cursor (fallback: Finder)
bash scripts/raycast/kingdom-raycast.sh open-repo procedural-city

# Run venture local tests (via API)
bash scripts/raycast/kingdom-raycast.sh run-tests kingdom-ops
```

## Deep link URL scheme

```
http://127.0.0.1:5173/?venture=whatsapp-voice&tab=run
```

Tabs: `run`, `overview`, `tech`, `architecture`, `data`, `tests`, `experiments`, `models`, `cicd`

## CLI (non-Raycast)

```bash
npm run orchestrator:open -- --venture whatsapp-voice --tab run
```

Data paths (generated by sync):

- `config/dashboard-services.json` — service registry (ports, start commands)
- `public/data/venture-registry.json`
- `public/data/manifests-index.json`
