# YouTube house video style — durable craft log (2026-08-11)

**Scope:** All future Agent Cut / YouTube Editor Lab videos (not only Video 1).  
**Repo:** `~/Projects/youtube-editor-lab`  
**Human:** Avinash — lock these for house style.

## Audience

- Layman + curious.
- Broader camp: family, college, work — any political aisle.
- Bias / hard topics: mechanism of ignorance, not dunking on stupidity.

## Voice

- **Friend conversation**, not lecture.
- Open like: “Okay. Remember those family groups…?”
- Clear short sentences. No stacked catch-up paragraphs.
- Too verbose = boredom. Prefer silence + picture over extra words.

## Show, don’t tell (Rajamouli)

- Cold open = **lived scene** before naming the topic.
- No jargon-first open. No “is it stupidity?” framing.
- Arc: show → recognition → curiosity → name mechanism → science → learning payoff.

## Stoppages / sink-in

- After key lines: stop. Let the viewer land.
- Script marker: `[…]`
- Teleprompter: `[pause]`
- B-roll tag: `HOLD_sink_*` (1s / 2s / 3s as needed)
- Picture holds while the idea sinks in.

## Analogies

- Use **broad-audience** analogies between ideas (sunglasses, playlist, wall/fortress, referee, tasting food you swore you’d hate).
- One analogy at a time; then pause.

## Montages / graphics

- `MONTAGE_*` fast images fill gaps and buy sink-in time.
- First term debut: font montage + definition + bg blur — `PLACEHOLDER_term_flash_<slug>` (see repo `docs/graphics-term-flash.md`).
- Map-zoom / labelled-map / 3B1B Manim tools = **later**; placeholders until Graphics Desk.
- Long-term visual bar: 3Blue1Brown-style explainers, reusable across videos.

## Quality over runtime

- Do **not** pad VO to hit a minute target.
- Runtime serves clarity and retention, not a stopwatch.
