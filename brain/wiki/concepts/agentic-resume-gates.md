# Agentic resume claim gates

Maps Kingdom milestones → honest resume / LinkedIn language. Use with Track A resume and [[concepts/agentic-interview-prep]].

**Rule:** Until a gate passes, prefer “shipped lab systems with eval/ops discipline,” not “production at N users” or “paid customers.”

## Gate table

| Venture | Milestone | Stronger claim you can unlock | Until then, say |
|---------|-----------|-------------------------------|-----------------|
| **WhatsApp** [[ventures/whatsapp-voice]] | **Phase 8+** — real pilot / paid touch / signed intent | “Deployed WhatsApp agent into broker workflow; qualify → booking with live outreach” (FDE gold) | “Built FSM lead-qualify agent + outreach CRM; dogfood demos; phase-gated delivery” |
| **YouTube** [[ventures/youtube-editor]] | Timeline/preview **or** one dogfood video with provenance trail | “Shipped anti-slop editor that produced [video] with mandatory clip provenance” | “Multi-agent Cut Control lab with formula lint + provenance schemas (in progress toward publish)” |
| **Comic** [[ventures/comic-engine]] | Public demo + **eval metrics** on GitHub README (V1 board already 22/22) | “Production-minded multimodal pipeline with VLM eval gate pass rate X% and usage metering” | “Shipped end-to-end pipeline with VLM rubric gates and usage.db” (already usable) |
| **City** [[ventures/procedural-city]] | One crisp **LLM Scene Director + budget gate** case study (not all 92 phases) | “Long-horizon LLM scene direction under hard API spend ceiling with structured-output validation” | Same, scoped to Stage E / budget — don’t wait for Phase 92 |
| **Kingdom ops** [[ventures/kingdom-ops]] | Stable sync + public/architecture note | “Multi-agent command center syncing gates, spend, audits” | Already fair as Independent Builder bullets |

## Claim language cheat sheet

| Weak | Strong (after gate) |
|------|---------------------|
| Prototyping diffusion models… | Shipped generative pipeline with **eval gate** and **provenance** |
| Chatbot for leads | **FSM agent** qualify → booking with handoff + audit |
| AI video editor | **Multi-agent desk** with formula lint + **mandatory clip provenance** |
| Built with LangChain | Built **custom orchestration**; can discuss LangGraph/MCP tradeoffs — decision note [[agentic-stack-guidance]] |
| Scaled AI product | Lab system with **spend ceilings** and **usage accounting** (until pilot metrics exist) |

## Apply sequence vs gates

1. **Now (pre-pilot):** Apply with Track A using Comic V1 + YouTube lab + WhatsApp dogfood language; seed Job Jugaad wishlist (30).
2. **After WhatsApp Phase 8:** Rewrite LinkedIn Featured + top WhatsApp bullets; prioritize FDE / customer-agent roles.
3. **After YouTube dogfood publish:** Add link + provenance appendix; targeting agent platforms + media AI.
4. **Comic README metrics:** Attach eval report; Braintrust / W&B / eval-heavy roles.
