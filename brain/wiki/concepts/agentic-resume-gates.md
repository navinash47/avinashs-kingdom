# Agentic Resume Claim Gates

Maps Kingdom milestones to honest resume and LinkedIn language. Use with Track A resume.

**Rule:** Until a gate passes, use present continuous tense. Focus on vision, approach, evaluation, and brief results. No specific numbers.

## Gate Table

| Venture | Milestone | After gate | Before gate |
|---------|-----------|------------|-------------|
| **WhatsApp** | Phase 8+ pilot | "Deployed WhatsApp agent into broker workflow. Qualifying leads and booking site visits." | "Building lead-qualify agent for real estate brokers. Progressing toward pilot." |
| **YouTube** | Dogfood video | "Shipped anti-slop video editor with clip provenance." | "Building multi-agent video editor. Working toward first video." |
| **ComicMainEngine** | Public demo | "Built generative comic pipeline with VLM evaluation gates. Initial phase completed." | "Building comic generation with VLM rubric evaluation." |
| **Procedural City** | Scene Director case study | "Built LLM scene director for 3D city generation under budget." | "Building 3D city generator with LLM scene direction. Progressing through development." |

## Claim Language Guide

| Weak | Strong |
|------|--------|
| Prototyping diffusion models | Built generative pipeline with evaluation gate and provenance |
| Chatbot for leads | Built lead-qualify agent with handoff and audit trail |
| AI video editor | Built multi-agent video desk with clip provenance |
| Built with LangChain | Built custom orchestration with evaluation gates |
| Scaled AI product | Built system with spend ceiling and usage tracking |

## Writing Pattern

For each project:
1. **Vision:** What problem are you solving?
2. **Approach:** How are you building it?
3. **Evaluation:** How do you measure quality?
4. **Result:** Brief outcome (or present continuous if in progress)
